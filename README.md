# Wild Vaccines

## Objective

***Why do individuals vary in their response to immunisation?***

## Setup

To set the julia environment up follow the steps below (taken from <https://julialang.github.io/Pkg.jl/v1/environments/>):

1. Clone the current repository (`https://github.com/SimonAB/Apodemus_vaccines.git`)
2. In [VSCode](https://code.visualstudio.com), the folder of the cloned repo
3. Launch Julia v1.4 -- in VSCode, do this using the Julia extension by typing `⌘⇧P`, then `Start Julia REPL`. VSCode may ask which environment to use, in which case pick the cloned repo.
4. Enter Pkg mode `]`
5. Activate local environment `activate .`
6. Instantiate Packages `instantiate`
7. [Optional] Precompile local env: `precompile`
8. Exit Pkg mode `<Backspace>`.
